Selenium Java SauceDemo Automation
Overview

This project contains UI automation tests for the SauceDemo application using Selenium WebDriver, Java, and TestNG.

How to Run
Clone the repository.
Open the project in IntelliJ IDEA.
Make sure Maven dependencies are downloaded.
Run the TestNG test classes.
Application

SauceDemo is used as the demo application for practicing Selenium automation.
